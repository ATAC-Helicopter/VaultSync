# What's New

## [1.3.5]

### Backup reliability
- Archive uploads stay responsive on slow links and report progress more consistently.
- SMB archive uploads use safer defaults, with an option to disable parallel writers.
- Backup storage usage now keeps the last known value when a target is temporarily unavailable.

### Tray & updates
- macOS tray menu uses the native menu for reliable opening.
- Update banner now shows the installer/release action when a patch isn’t available.
