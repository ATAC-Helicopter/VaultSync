# What's New

### Cross‑machine history
- **Sync backup history** across machines with the destination metadata store.
- **More reliable imports** on shared drives and network storage. {sync}

### Backup experience
- Cleaner **backup cards** and **history panels** with clearer status details.
- Storage totals and per‑project usage visuals now match actual data.
- New **“Open folder”** action in backup history.
- Cancel is clearer and cleans up properly (no leftover partials). {cleanup}

### Project setup
- No more sample “default” projects; empty lists stay empty until you add your own.
- Scroll layout now behaves better at higher DPI (thanks for the report).

### macOS & Windows reliability
- Network mounts are **safer and more consistent** across platforms.
- Better handling for *read‑only* or *unreachable* destinations. {stability}
- Arabic UI fallback fonts now render headers and labels correctly.

### Updates
- A **“What’s new”** popup now appears after updates. [Release notes](https://github.com/ATAC-Helicopter/VaultSync/releases)
- Rich text supports **bold**, *italic*, `code`, ~~strikethrough~~, and {badges}.
