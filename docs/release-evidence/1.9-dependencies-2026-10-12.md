## Implemented boundary

The read-only dependency prototype requires each node's supplied current passed
measurement and every named dependency group. Alternatives can cover one group;
they cannot substitute for a separate required key or reader. Missing references,
empty groups and stale/failed/interrupted/unsupported/simulated/confirmed
observations remain inspectable and cannot supply measured coverage.

Validation rejects ambiguous identities, unsupported relations, cycles and
excessive graph size/depth before assessing any node, including disconnected
nodes and unused alternatives. Shared DAG paths obey the longest-path bound.
Results copy candidate lists and preserve historical observations.

These are synthetic fixtures and review-only in-memory types. No serialized
format, observation discovery/conflict precedence, producer authentication,
artifact inspection, failure-domain scenario, secret acquisition, repository
mutation, UI/CLI integration or device access is implemented. The result does
not establish overall recoverability. Joint architecture approval stays open.
