   Record each measured stage against the same image/run/build identities.

5. Only after an explicit release decision, choose the beta version suffix,
   update metadata/package consumers, verify BUG-19024 against real packages,
   merge the reviewed beta scope into `Dev`, and run the beta asset workflow.
   Review the resulting binaries and notes before any prerelease publication.
