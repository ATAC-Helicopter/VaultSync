## Delivered scope

A sealed staged image and read-only exclusive target claim now produce an
immutable review description with a unique review UUID, operation UUID, verified
image/capture/generation/content-root assessment, exact target identity/geometry
and full overwrite byte range. Only the newest review can be acknowledged. The
exact review/operation response is consumed once before asynchronous rechecks;
wrong IDs, replay, superseded or concurrent replies cannot acknowledge twice.
A stale reply cannot consume the replacement review.

Rechecks independently observe the native topology again: boot/namespace,
selected record, mount/swap/holder flags and repository ancestry must remain
valid. The held descriptor is revalidated without reading bytes. Stage/target
liveness and the original 30-second deadline are checked after asynchronous work.
A monotonic deadline supplements UTC expiry so clock rollback cannot prolong a
claim. Invalid topology, access/I/O failure or expired/closed resources release
that target claim. Acknowledgement interruption consumes an admitted review;
cancellation before gate admission is not an accepted response.

This is a review exchange prerequisite, not proof of human interaction, Offline
state, authenticated privilege or writable device authority. No UI or privileged
protocol accepts the result yet. The future writer must never accept this boolean
as execution permission. Unknown use remains Unknown. No new UI strings or
product diagnostics fields are introduced; exact identifiers stay private.
