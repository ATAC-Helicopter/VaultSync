## Corrections and intentional benchmark exceptions

- Navigation explicitly uses CancellationToken.None because the ambient updater
  cancellation source does not own navigation/history. Existing route guards keep
  their own lifecycle; update cancellation cannot become a navigation dependency.
- Changelog section regex grouping makes the intended lookahead alternatives explicit.
- Verification validates repository/full SHA/authorized-ref syntax before invoking
  any process. GH executable and subject/proof paths are absolute. Argument vectors,
  channel-specific authorization, exact assets and online/offline verification remain.
- Release checksum and Python benchmark outputs are exclusively created with private
  permissions. Traversal/ambiguous leaf names, existing files, symlinks and hardlinks
  cannot clobber prior evidence. The native benchmark also uses CreateNew.
  The operator explicitly chooses its local directory; this is not a remote path API.
- The Sonar job installs only a pinned binary coverage wheel. Existing codec tests
  are genuinely measured with scripts and experiments; thresholds are unchanged.
- Three line-scoped NOSONAR annotations review only the fixed-seed public benchmark
  calls: C# Random(1996), Python random-proxy bytes and GUID-shaped generated text.
  They are not used for production identifiers, cryptographic material, credentials
  or protection operations. Changing the corpus to nondeterministic crypto randomness
  would invalidate comparisons. No global rule, product RNG or file is excluded.
  Initial findings: AaFTRsg3CaaKS4UBl4TA, AaFTRsh2CaaKS4UBl4TQ,
  AaFTRsh2CaaKS4UBl4TR. These are documented non-security exceptions, not claims
  that a general-purpose PRNG is safe for secrets.

The signing/inventory changes preserve package bytes, updater schema and asset names.
No release was signed, dispatched, uploaded or qualified by these unit fixtures.
Operator proof output must use a fresh name rather than replacing retained evidence.
