# Synthetic file capture — 2026-10-13

Owner: VS-1904 / #492. Preparation: `work/1.9-roadmap-realignment`, PR #736

The prototype captures exact supplied synthetic bytes into new temporary regular
files with a 128 KiB buffer. A header identifies partial workspaces. Payload
flush precedes manifest publication, whose flush precedes completion. Requests
with invalid identity/generation/geometry/capacity fail before workspace creation.
Source paths and writable devices are never opened. Partial artifacts are retained;
callers own cleanup. Final publication finishes after its cancellation boundary.

Fourteen tests compare a capture byte for byte against an independently encoded
Python fixture, verify captured files through the separate manifest reader, check
512/4096-byte sectors and multi-buffer content, and inject truncated/extra source
bytes, source I/O failure and cancellation. Injected failures before finalization
leave only incomplete metadata. Input remains unchanged and caller-owned.
