# Synthetic file reconstruction — 2026-10-13

Owner: VS-1907 / #495. Preparation: `work/1.9-roadmap-realignment`, PR #736
into `Dev`. Previous implementation head: `c9be653`.

The file prototype verifies the manifest/completion and stages raw payload bytes
during digest validation, then reconstructs from those snapshots. It creates no
reconstructed output until all input checks pass. Raw, explicit-zero and mixed
maps produce exact independently expected bytes. Target length and whole-file
read-back SHA-256 are checked before success. Memory, parts and staging/output
sizes have explicit fixture limits.

Eleven cases cover independent encoded fixtures, original input mutation after
EOF, corrupted/truncated/missing input, interrupted staging, excessive counts,
oversized zero images and capture-to-reconstruction with the original source
closed. They do not open physical devices, mount a filesystem or boot a system.
