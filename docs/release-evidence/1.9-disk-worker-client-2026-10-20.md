## Delivered boundary

Core can now launch the fixed adjacent worker without arguments, PATH search or
a shell, send a correlated request and EOF, and consume a bounded strict reply.
A missing or directly symlinked executable is unavailable. Complete success needs
header/version/operation/UUID, body bounds, valid schema, EOF, empty diagnostics
and exit zero. Failed exchanges return no inventory. Unsupported or incomplete
observations preserve their typed meaning. No raw identifiers or exception text
are added to diagnostics. Read-only metadata stays on the private pipe.

The first failing exchange task triggers cleanup. The parent deadline is 35
seconds; caller cancellation remains cancellation. A running child receives a
process-tree kill request, followed by an exit wait of at most two seconds. This
is not containment or reliable termination of detached descendants. The real
worker starts no children. Fixed-path selection is not publisher verification or
proof that an installation/ancestor directory has not been modified.

The test build copies worker files only into its own output for real-process
tests. Desktop/recovery integration and release assets remain unchanged. This
is not an authenticated or elevated helper, device access or write permission.
