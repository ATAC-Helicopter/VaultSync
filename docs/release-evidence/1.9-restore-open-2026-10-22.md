## Delivered scope

The internal Linux x64 opener now replaces the private lab's writable opener for
actual engine execution. It accepts only the sealed stage, exact request, bound
unstarted product journal and recent expected inventory. Independent inventories
and held native inspections surround openat2 O_RDWR/O_EXCL; every path component
refuses links, with no fallback. Original image/staging/journal ancestry must be
uniquely outside the target and retain exact whole-disk identity. Invalid, changed,
disposed, started or mismatched inputs refuse. Acquisition alone never writes or
appends records. Ownership transfers only after final checks; other exits release
the descriptor. Hosted follow-up separates typed admission from acquisition
ownership, scopes native declarations, checks descriptor conversion, uses an All
ancestry predicate and passes explicitly terminated UTF-8 bytes to the syscall.
Native flags/admission/write order are unchanged. See [full contract](../LINUX_RAW_RESTORE_OPEN_1.9.md).

This is not operation authorization. No public API, elevated endpoint, writable
worker protocol, desktop route or recovery launcher reaches it. The existing
inventory worker remains read-only. Future broker consent/build/peer/offline
authority and exclusive operation lifetime remain mandatory before production
use. Creating a journal or acknowledging a preview never supplies permission.
