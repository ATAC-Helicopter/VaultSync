## Implemented

The [adapter contract](../LINUX_BLOCK_READ_1.9.md) specifies same-privilege Linux
x64 admission, fresh observation bracketing, fixed read-only/exclusive open,
held statx/getter identity and repeated read checks. No arbitrary path/native
operation or writable source is exposed. Wrong platform, in-use/ambiguous/stale/
unsupported selections and unavailable or changed bindings refuse with no source.
Unknown use remains Unknown; this is not global offline/source-consistency proof.

The parent inventory cleanup also explicitly opts out of caller cancellation
while waiting for a killed worker, retaining its two-second exit-wait bound.
This addresses the two S8949 findings on 484be54 without changing cleanup
semantics or excluding a rule. That historical gate failed; a new exact-head

## Measured virtual-device execution

Pinned Debian/QEMU x64 UEFI, private generated images only. No host raw device,
network adapter, shared folder or credential is attached. The source and firmware
hashes match the earlier pinned lab. This copies the disposable guest overlay
with its existing cloud-service masks; it is not independent recovery media.

The actual Core adapter, through a private self-contained invariant harness:

- Refuses the mounted OS disk and changed selection before returning a source.
- Refuses a second exclusive claim while the first reader owns its descriptor.
- Reads all **134,217,728 bytes** of the generated 512-byte-sector source. Its
  SHA-256 matches an independently computed all-zero baseline; the write API
  refuses. Both descriptor geometry and seek/read offsets execute natively.
- Closes the first source and successfully reopens it, demonstrating claim release.
- Reads the final 4,096 bytes of a kernel read-only 4,096-sector source.
- Keeps that source open while QMP removes only the generated target through a
  PCIe root port. A subsequent read refuses and the stream closes its descriptor.

Final VM exits 0, normal poweroff, no timeout: **45.16 seconds total** boot and
probes, not throughput. All seven retained cases pass. The macOS public entry
returns UnsupportedPlatform without attempting Linux device access.

The first QMP attempt could not remove a root-bus PCIe device and the host
terminated that run. It is not recorded as normal shutdown or passed hot removal.
The final probe uses a hotplug-capable root port and selects known synthetic
fixture roles through observations, avoiding PCI enumeration assumptions.

Private probe sources, images and logs: `/tmp/vaultsync-native-read-20261020/`.
