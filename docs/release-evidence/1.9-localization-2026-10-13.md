placeholder errors. Source inspection found missing credentials/removal and
updater/relaunch keys, fixed Guide/Recovery loading messages and coverage-window
labels. Recovery displayed Core's English headline/counts; installer completion
paths shared one translation despite requiring distinct instructions.

Nine keys are translated in all 19 languages; the 1.9.0 baseline now has 1,931
keys. Six English phrases in Dutch, Indonesian and Polish were translated.

payloads were preserved. Coverage labels use flexible columns. Guide/Recovery
cached text reapplies on language changes, preserving search and filter; numeric
background results are formatted at UI application time.

Catalog/source validation now fails on missing/extra/duplicate/blank/non-string
entries, invalid English values, placeholder differences, missing declared
languages, unresolved static references and fixed recognized UI strings/setters.
English matches remain review candidates; static analysis does not prove natural
language quality or cover every indirect expression. AGENTS/CONTRIBUTING require
translation and review of every new visible application string.

Draft assembly also compares Localization source inputs before reusing packages.
An isolated real Git fixture confirms that a locale-only change rejects packages
built from the previous source. No user backup, database, destination or secret
was modified for this audit.
