## Delivered

The public Linux x64 path requires the existing exclusive source adapter and
kernel read-only state. It inspects GPT before storage allocation, streams and
hashes all bytes, checks source EOF/GPT again, flushes output files, independently
verifies the complete raw image/GPT, flushes directories, then publishes through
rename-no-replace and a final parent flush. Storage holds native directory/file
descriptors, refuses symlink components, requires a private current-UID ext4
parent and creates only new private directories/fixed files. Full allocation
preflight precedes payload copying. Existing images and empty directories are
never replaced. Interrupted or failed attempts remain private partials; a failed
post-rename sync explicitly reports PublicationUnconfirmed without success data.

## Native disposable VM

Pinned Debian source SHA-512 and QEMU UEFI firmware match the retained laboratory
inputs. No host raw device, network adapter or shared folder was attached. The
current Core code and a private self-contained Linux x64/invariant harness run
on generated virtio-blk GPT fixtures: **65,536 bytes / 512 sectors** and
**524,288 bytes / 4,096 sectors**. These are tiny structural fixtures, not bootable
ext4/NTFS filesystems or measured support-capacity claims.

All **20 native cases pass**, normal guest poweroff and QEMU exit 0, no timeout;
38.96 seconds is total boot/probe duration, not throughput. Both captures publish
and reopen through the raw reader with independently generated payload SHA-256
values. Private permissions, exact existing-image preservation, empty-directory
no-replace, writable-source refusal, leaf and ancestor symlink refusal, nonprivate
parent refusal and insufficient-space preflight execute natively. The write
operations affect only guest regular output files; device descriptors are read-only.

Earlier attempts remain failed evidence: ISO filename preservation prevented the
first probe execution; SCSI WWID returned EINVAL and inventory refused; changing
controller layout required a fresh firmware boot identity; the lab selector
initially counted inherited partition identifiers along with whole disks. The
final selector requires WholeDisk and explicit bootindex. No production I/O guard
was weakened. The SCSI refusal remains a known qualification limit.

Native binaries are development laboratory builds from the hash-bound source
above, not final signed release assets. Unit-injected interruption/I/O cases are
not promoted to measured power-loss outcomes. No five-stage recovery loop,
privileged authentication, desktop/media integration, device restore, exact
1.8.9 upgrade or new release signing run is qualified. Four disk profiles stay
candidates; #492 remains open/In progress and #736 remains draft.
