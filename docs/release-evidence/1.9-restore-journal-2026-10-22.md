## Delivered boundary

An internal native journal now replaces the lab-only durable provider. Independent
fresh target/boot/namespace observations and the held parent's unique repository
ancestry precede any entry creation, then are rechecked before publication.
Unknown, changed, ambiguous or target storage refuses. Private ext4 records are
preallocated, headers/files/directories flushed and operation directories
published with rename-no-replace. Capture/staging retain their old file names.
The journal uses separate `journal.header` / `records.bin` roles and partial prefix.

The internal version-1 binary header/frames bind bounded image/operation/review/
geometry facts with explicit UUID/numeric order and a SHA-256 chain. A validated
state machine enforces exact chunk intent/acknowledgement, terminal order and
record budget. A failed/unconfirmed append permanently closes the writer to
further appends. Stream alias/position/binding/state mistakes refuse.
Inspection preserves incomplete/interrupted/failed/byte-verified distinctions;
it is never an authorization, authorship proof or automatic resume token.
The engine now handles invalid journal binding and an already-terminal refusal
without leaking an unhandled exception, including a second cleanup failure.
See [full contract and byte table](../RAW_RESTORE_JOURNAL_1.9.md).
