Unity documents `.pdata` as saved Profile Analyzer data in its
[official window documentation](https://docs.unity3d.com/Packages/com.unity.performance.profile-analyzer@1.4/manual/profile-analyzer-window.html).
The preset now excludes `.pdata` at root and nested paths, retaining unrelated
source/assets and files inside the ProfileAnalyzer directory. It does not exclude
all `.data` files or the entire profiling folder. Synthetic regressions retain
scripts, scenes, prefabs, settings, package manifests/locks and profiling tool code.
Users needing profiling history should clone the preset and remove these rules;
local exclusion-only rules cannot override them with an include.
