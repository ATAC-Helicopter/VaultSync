## Implemented boundary

The native capture parent no longer calls the GPT or full-image parser. A fixed
separate reader checks source GPT before allocation and after copying. Its new
flat bounded grammar carries at most 128 partition observations, no source names,
paths, descriptors, display strings or writable operation. The parent requires
canonical frames and matching geometry; absent/failed/timed-out/malformed readers
refuse without a parser fallback. The initial failure creates no image storage.

The existing inherited-pipe/peer transport now shares typed exchanges between
image and GPT operations while keeping their result magic and grammar distinct.
Trusted runtime warmup, child privilege drop and all-thread seccomp, independent
live parent kernel checks, terminal peer ACK, EOF, empty stderr, exit zero and
bounded cleanup remain mandatory. GPT input index 0 has length zero and cannot
supply metadata bytes. Its observed digest does not establish trusted provenance.

Copying explicitly restores held source position after the oracle. After exact
copy and source reinspection, capture flushes payload/metadata, seals them at 0400,
reopens the same inodes read-only with managed read caching disabled, and closes
all transaction-owned writable handles. Mandatory isolated full-image inspection
binds request identity/generation/root/geometry/copied payload hash. Independent
parent hashes bind exact encoded metadata and payload before publication.
Journal storage retains its original interface; image sealing is required only
for capture/staging providers. No new UI string or product diagnostic field.
