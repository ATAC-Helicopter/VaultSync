## Delivered behavior

`LinuxBlockInventoryService` reads fixed sysfs/proc metadata locations without
opening raw device contents, mounting, invoking tools or writing. Other platforms
return UnsupportedPlatform. It collects kernel device numbers, boot/namespace
observations, disk sequence, capacity, geometry, read-only flags and WWID/serial
candidates. Partitions inherit geometry and lower topology through their parent.
The normal missing partition `slaves` directory is accepted; a missing required
whole-disk topology directory is not silently treated as empty.

Mount/swap use and holder relationships propagate through the partition/stack
graph. Unknown swap paths or swap files remain unresolved. Any shared WWID or
serial token marks whole-disk identity ambiguity, even with different preferred
identifiers. Optical/virtual/stacked devices are not whole-disk identity candidates.
UniqueInSnapshot is not authenticated physical identity. Serial/boot observations
must be redacted for real machines; the public projection uses synthetic VM labels.

Limits are 256 entries, 4,096 relationship entries, 8 MiB cumulative text plus
bounded per-file sizes/names. Bad, denied, missing or excessive metadata returns
no devices. Bracketed topology/identity/geometry/boot/use reads reject changed
views. Cancellation propagates. This is not an atomic snapshot or an I/O deadline.

The use API has only Unknown and ObservedInUse. Current-namespace absence never
becomes Offline, write permission or a restore-preview capability. Device handles,
exclusive access, current authorization, repository ancestry and worker/channel
security remain separate prerequisites. No UI or file-backup behavior is changed.

## Native VM measurement

A private self-contained .NET 10.0.13 harness called the public Core API inside
QEMU 11.1.1, x86_64 TCG/Q35/UEFI, 1 GiB RAM and 2 vCPUs. The pinned Debian base
was verified against its retained SHA-512. Only disposable virtual files were
attached: a source overlay, two 128 MiB targets and the seed ISO. No host device,
shared directory, credential or network adapter was passed. The harness ran as
root through cloud-init; this does not qualify unprivileged desktop execution
or an authenticated/elevated VaultSync worker.

| vda1 / vda15 | inherited 512 / 512 | false | Direct mounts observed; parent linked |

The final snapshot is Observed; the native program exits 0 and the guest powers
