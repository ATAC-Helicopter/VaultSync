# macOS beta bundle version evidence — 2026-10-13

Owner: BUG-19024 / #778. Preparation PR: #736. This is native packaging
fixture evidence, not a beta package or installed upgrade qualification.

Apple requires three numeric components in `CFBundleShortVersionString` and
one to three numeric components in `CFBundleVersion`. The builder maps a strict
`X.Y.Z-beta.N` target to short version `X.Y.Z` and build
`X.Y.(1000*Z+N)`, with `N` from 1 through 998. The final `X.Y.Z` target uses
build `X.Y.(1000*Z+999)`. Thus successive beta builds precede that final
build, which precedes the next patch's first beta. Other prerelease labels,
build metadata, leading-zero components and out-of-range beta iterations fail
before packaging. The exact target remains in `VaultSyncReleaseVersion` and
the DMG filename; canonical release/project metadata still owns the target.

The focused Python cases verify ordering across 1.8.9 → 1.9.0 betas → 1.9.0
final → 1.9.1 beta, and reject ambiguous versions. On macOS, an isolated
temporary packaging fixture used `/usr/bin/true` as the executable and the
repository icon. `build_macos_dmg.sh` produced beta and stable DMGs. Both
`Info.plist` files passed `plutil -lint`; `codesign --verify --deep --strict`
passed; `hdiutil verify` reported valid checksums. Inspected fields were:

| Target | Short version | Build version | Exact target key |
| --- | --- | --- | --- |
| `1.9.0-beta.1` | `1.9.0` | `1.9.1` | `1.9.0-beta.1` |
| `1.9.0` | `1.9.0` | `1.9.999` | `1.9.0` |

The release workflow now checks all three fields on both architectures. This
fixture proves numeric metadata and script execution only. It does not prove
the real app launches, update/install precedence on target macOS versions,
exact 1.8.9 upgrade behavior or a signed/notarized distribution. Those checks
remain beta gates on the selected candidate.

Sources: [Apple short version](https://developer.apple.com/documentation/BundleResources/Information-Property-List/CFBundleShortVersionString),
[Apple build version](https://developer.apple.com/documentation/BundleResources/Information-Property-List/CFBundleVersion).
