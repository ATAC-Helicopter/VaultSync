# Tray menu

The tray menu mirrors key actions and status from the app.

## Sections
- Storage health: shows the current backup drive status and lets you recheck.
- Destinations: lists configured destinations and reachability, with a status pill.
- Recent backups: quick access to recent backups with keep/delete/open actions.
- Backup/Snapshot: start backup or snapshot jobs without opening the app.

## Actions
- Open VaultSync: brings the main window to the foreground.
- Backup all projects: runs a full backup of all configured projects.
- Snapshot all projects: creates snapshots for all projects.

## Tray backup widget
When a backup is started from the tray, a small widget shows progress until completion.
