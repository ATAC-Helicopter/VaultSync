# Quick start

This guide gets you to a verified backup quickly.

## 1) Add a project
- Go to Projects.
- Click Add project and choose the folder you want to protect.
- Give it a clear name (this appears in backups and the tray menu).

## 2) Choose a destination
- Open Settings > Backups.
- Simple mode: set a single backup root path.
- Advanced mode: add one or more destinations with aliases.

## 3) Run a manual backup
- Open the Backups page.
- Click Backup for a project to create your first backup.

## 4) Verify the result
- The Backups page lists the latest snapshot and status.
- Click a backup to view details and verify size/time.

## Tips
- Use a local SSD for fastest backups.
- For NAS or SMB, see `Network-Shares.md` for performance tips.
- If you change destinations, use “Check drive health” in the tray menu.
