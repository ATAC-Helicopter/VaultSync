# SonarQube Cloud

VaultSync uses SonarQube Cloud for repository code-quality analysis.

## Plan

Use the SonarQube Cloud OSS plan for the public open-source repository.

- Cost: free for public open-source projects.
- Repository scope: public repositories only.
- Branch analysis: unlimited.
- Pull request analysis: unlimited.
- Organization members: unlimited.

Do not move VaultSync to a paid SonarQube plan unless the project governance explicitly approves it.

## GitHub Setup

Import the repository into SonarQube Cloud and configure these GitHub repository settings:

- Secret `SONAR_TOKEN`: generated by SonarQube Cloud.
- Variable `SONAR_ORGANIZATION`: SonarQube Cloud organization key.
- Variable `SONAR_PROJECT_KEY`: SonarQube Cloud project key.
- Optional variable `SONAR_HOST_URL`: defaults to `https://sonarcloud.io` when omitted.

The workflow is intentionally guarded. If the secret or required variables are missing, the check exits successfully with notices instead of failing every push.

## Workflow

The workflow lives in `.github/workflows/sonarqube.yml` and runs on:

- Pull requests into `Dev`, `Stable`, and `release/v1.8`.
- Pushes to `Dev`, `Stable`, and `release/v1.8`.
- Manual `workflow_dispatch` runs.

Keep the SonarQube check non-required until the initial project import, exclusions, and quality gate are tuned.
