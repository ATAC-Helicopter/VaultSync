FAQ

Answers to the main questions new users tend to have before downloading.

What is VaultSync?

VaultSync is an open-source backup tool for NAS, local storage, and external drives. It is designed to make backups more transparent, reliable, and easier to manage from a desktop app.

Is VaultSync a cloud backup service?

No. VaultSync is centered around storage you control directly, such as NAS devices, local disks, and external drives.

Does VaultSync support encrypted backups?

Yes. VaultSync includes encryption support to help protect stored backup data while keeping the workflow practical and visible.

Where can I download VaultSync?

You can download the latest version from the GitHub releases page. A Microsoft Store version is also on the way for users who prefer a more convenient installation path.

Will the Microsoft Store version be different?

No. The Store release is intended to be the same core VaultSync application, just delivered through a more practical install and update channel.
